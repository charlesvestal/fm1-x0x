X0X

Back up your project

Save the project on your FM-1 to a file on this computer, and load it back later. Keep as many projects as you like this way, and keep your songs safe while you try other firmware.

Connect the FM-1 by USB with X0X running, and use Chrome or Edge. There is nothing to install.

Plug in the FM-1 running X0X.

Back up

This saves the project to an .x0b file: the sounds, all 32 patterns, the song, the knob motion, the tempo and the settings. X0X can keep playing. If you have changes that aren't saved yet, stop X0X first so they go in the file too.

Restore

This puts a backup back on X0X, and it replaces the project there. Stop X0X first. X0X checks the whole file before anything changes. Then its screen asks RESTORE FROM USB? Press SEL on the FM-1 to restore, or HOME to keep what you have.

  • A backup doesn't hold your break loops. Keep their WAV files, and load them again on the break loops page.
  • A cut cable or a damaged file changes nothing. Even a power cut while X0X writes leaves either the old project or the new one, never a mix.
  • A backup made with an earlier version of X0X restores in a later one.
  • The browser asks once for permission to use MIDI with SysEx. Allow it, and close other apps that use the FM-1's MIDI first.
  • You can also back up from a terminal. Run python3 tools/x0x_backup.py in X0X's repository. It does the same, and makes the same files.
